Privacy by design

  • Demo data only: participant names and messages are hard-coded examples.
  • Local interaction: chat actions update the page in your browser session.
  • No sign-in: this lab has no authentication flow.
  • No production connection: no database or storage requests are made.
  • No secrets: credentials, access tokens, and private user records do not belong in this public demo.

What this lab does not prove

  • End-to-end encryption is not implemented here.
  • Real-time delivery and read receipts are not tested here.
  • Production authorization and RLS are not exercised here.
  • Message expiry in this simulator does not delete real files.

For security reporting, use the repository's SECURITY.md.
